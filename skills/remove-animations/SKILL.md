# Remove Animations

Inventory motion by frequency, purpose and effect on comprehension. Remove
decorative entrances on frequent surfaces, animation on keyboard actions,
and delays that block interaction. Keep feedback or orientation cues that
carry information, reducing movement where appropriate. Remove orphaned
timers, styles and state; don't replace removed effects with new effects.
Report the changes and what you retained and why. Use
[review animations](../review-animations/SKILL.md) for issues outside removal
scope. After edits, run [break UI](../break-ui/SKILL.md) and test the
resulting interaction with and without reduced motion.
