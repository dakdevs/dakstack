# Choreograph

Identify the element that explains the change, supporting elements and
what must stay still. Start together; overlap where the eye needs an order.
Sequence only when simultaneous motion obscures meaning. Keep stagger
short, allow interruption or reversal, and never delay interactivity for
decorative movement. Preserve the state change without motion for users
who request reduced motion. Use the [recipes](references/recipes.md).

Record the timeline and what stays still. Observe the actual sequence,
including rapid retriggers and exits. If you changed the UI, run
[break UI](../break-ui/SKILL.md) before calling it verified.
