# Animation Vocabulary

Look up the closest terms in the [glossary](references/glossary.md).
Give the most likely term first and explain what distinguishes it. If two
effects fit, say what visible detail would disambiguate them. Offer a short
phrase a designer could use to request it. Don't implement an effect merely
because the user asked what it is called.
