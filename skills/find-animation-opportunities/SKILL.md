# Find Animation Opportunities

Inspect the screen, interaction frequency, input modalities and existing
feedback. Suggest motion only where it explains state or spatial origin,
improves feedback, or provides deliberate rare-use delight. Reject motion
that slows a frequent action, distracts from data, or blocks interaction.
Specify trigger, property, budget, exit/interruption and reduced-motion
fallback for accepted ideas. Report rejected ideas and the strongest
recommendation. This skill is read-only.

Use [animate](../animate/SKILL.md) for implementation only when authorized,
or [choreograph](../choreograph/SKILL.md) for a coordinated sequence.
